# Як долучитися

Дякуємо за інтерес до «Колеса Історії»!

## Перед початком

1. Архітектурні рішення — у [docs/decisions/](docs/decisions/).
2. Ігрові правила — у [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md). Зміни правил спершу обговорюються в issue.
3. Мова документації, коментарів і UI — українська. Ідентифікатори в коді, назви гілок і повідомлення комітів — англійською.

## Процес

- Гілки — англійською, `kebab-case`: `feat/...`, `fix/...`, `chore/...` (напр. `feat/wheel-advantage`).
- Коміти — [Conventional Commits](https://www.conventionalcommits.org/) англійською:
  `feat(engine): add wheel with advantage`. Одна логічна зміна — один коміт.
- Перед пул-реквестом: `./gradlew spotlessApply check` має бути зеленим.
- Нова залежність — лише з обґрунтуванням (навіщо, розмір, вплив на старт і пам'ять клієнта, чи можна
  обійтися ~50 рядками власного коду), суттєва — через ADR у `docs/decisions/`.

## Головні правила коду

- Рушій (`engine`) детермінований: без IO, часу, `Random`, `HashMap`, `double`.
  Якщо ArchUnit падає — виправляйте код, а не правила.
- Числа балансу — лише в контенті (YAML), не в коді.
- Тексти UI — лише через i18n.
- Кожна нова система рушія — з тестами детермінізму й інваріантів.
