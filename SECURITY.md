# Політика безпеки

## Підтримувані версії

Проєкт ще не має випусків; виправлення безпеки робляться лише в гілці `main`.

## Як повідомити про вразливість

Не створюйте публічний issue. Скористайтеся приватним звітом GitHub
(вкладка **Security → Report a vulnerability**) і опишіть:

- уражений компонент (клієнт, сервер, протокол, файл світу);
- кроки відтворення;
- можливий вплив.

Ми відповімо протягом 7 днів.

## Що вважається вразливістю

Особливо важливі: віддалене виконання коду через мережевий протокол або файл світу, обхід
автентифікації на окремому сервері, витік прихованого стану світу (туману війни) іншим гравцям,
витік токенів гравців.
