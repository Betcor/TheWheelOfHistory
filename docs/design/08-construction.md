## 8. Будівництво

### 8.1. Міста

Провінції мають рівень урбанізації (1–5). Будівництво й розвиток міст підвищує ВВП, науку, населення та вартість провінції.

Міста видно на карті: не лише столиця, а й інші міста держав (за рівнем урбанізації провінції). Як саме позначати
рівні й скільки міст має держава на старті — вирішити разом з економікою (етап 5).

### 8.2. Типи споруд (початковий набір)

| Категорія | Споруди |
|---|---|
| Економіка | фабрика, шахта (на родовищі), банк/біржа, торговий порт |
| Оборонка | військовий завод, укріплення (рівні 1–5), берегова оборона |
| Військо | верф, аеродром, військова база, ракетний комплекс |
| Наука | університет, НДІ, науковий центр, космодром |
| Суспільство | лікарня, храм, пропагандистський центр |
| Енергетика | електростанція, АЕС (потребує урану й технології) |
| Унікальні | один на країну або на світ: «Світова біржа», «Космічна програма», «Міжнародний науковий центр» тощо |

### 8.3. Процес будівництва

Замовлення → оплата → N років → колесо результату (§2.2). Перевага залежить від стабільності, корупції (ідеологія/підкласифікація), технологій, відомих людей, інфраструктури провінції. Ідеологія змінює вартість (наприклад, соціалізм дешевше будує заводи, теократія — храми).

### 8.4. Колонізація нічийних земель

Експедиція → колесо (успіх / опір корінного населення / провал / «міжнародний скандал»). Колонізація — розширення без війни, але вимагає грошей і стабільності.
