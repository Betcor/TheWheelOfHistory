## 13. Дипломатія

### 13.1. Дії між державами

| Дія | Тип | Ефект |
|---|---|---|
| Пакт про ненапад | двостороння угода | порушення = великий штраф до довіри |
| Торговельна угода | двостороння | +ВВП обом, обмін ресурсами |
| Союз | двостороння | взаємний захист, спільні запити на війну |
| Альянс | багатостороння | блок з назвою, спільні рішення, статут |
| Обмін технологіями | угода | передача технологій |
| Ембарго | одностороння | заборона торгівлі |
| Визнання / невизнання легітимності | одностороння | впливає на легітимність цілі |
| Засудження | одностороння | −вплив цілі, +casus belli для інших |
| Гарантія незалежності | одностороння | автоматичний привід для війни з агресором |
| Оголошення війни | одностороння | див. §10.7 |
| Мирний договір | угода | див. §10.7 |

Угоди між гравцями приймаються **рішеннями гравців**. NPC відповідають на пропозиції через колесо з вагами (§14.3). Колесо також визначає наслідки угод: реакцію населення, ефективність торгівлі.

### 13.2. Довіра й репутація

- Кожна держава має **репутацію** в очах інших. Порушення договорів, зради, неспровоковані війни знижують її.
- NPC пам'ятають зради й враховують репутацію у своїх рішеннях.
- Історія всіх угод і зрад записується в енциклопедію.
