# 0023. CLI генерації держави

- **Статус:** прийнято
- **Дата:** 2026-09-29

## Контекст

Ланцюжок коліс генерації (ADR 0022) перевіряли лише тести. Автору контенту й балансу потрібно швидко побачити
державу, яку дає конкретний seed: чому колесо дало такий результат, які мітки й модифікатори держава отримала,
як читається передісторія з реальною назвою. Світу й карти ще немає, тож релігії світу, ресурси й сусідів хтось
має задати ззовні.

## Рішення

- **Команда `country` у `tools:sim`:** `./gradlew :tools:sim:run --args="country --seed N"` друкує картку держави:
  назву й кандидатів, лад, релігію, розвиненість за галузями, ВВП, ІЛР, армію, ядерний статус, жетони, стріки,
  передісторію, людей, мітки, модифікатори й релігії світу. Параметри: `--countries` (розмір світу для таблиці
  кількості релігій, типово 20, межі 1..1000), `--resources id,id` (ресурси держави, поки немає карти; невідомий
  ресурс — помилка виклику), `--rolls` (усі обертання: результат, кидок, перевага з поясненням, фінальні ваги
  секторів), `--content DIR` (контент з каталогу — для правок балансу без перезбирання).
- **Світ з одного seed-а:** `Rng.of(seed)` → релігії світу з потоку `religions`, держава — з потоку `country:0`,
  без сусідів і зайнятих назв. Так само світ будують інтеграційні тести, тож CLI відтворює їхні держави. Коли
  з'явиться `WorldState`, CLI перейде на справжнє створення світу, і вивід для тих самих seed-ів зміниться.
- **Інструмент лише показує:** уся логіка — у рушії; CLI бере назви з контенту й форматує числа (відсотки з
  базисних пунктів, типографський мінус).
- **Тексти — у `tools/sim/src/main/resources/i18n/sim_uk.properties`**, а не в коді й не в клієнті (інструмент від
  клієнта не залежить). Підстановка `{0}` — простою заміною: `MessageFormat` ковтає апострофи.
- **Коди виходу:** 0 — успіх, 1 — помилка гри (`GameException`: невалідний контент, порушений інваріант; друкується
  ключ коду й подробиці — тексти кодів живуть у клієнті), 2 — неправильний виклик (текст помилки й підказка).

## Наслідки

- Вивід CLI не є стабільним форматом: для аналізу балансу буде окрема команда з CSV (`world`).
- Сусідів CLI не задає, тож фрагменти передісторії з сусідом не випадають — з'являться разом зі світом.
