# 0045. Актор сесії й порожні роки

- **Статус:** прийнято
- **Дата:** 2026-10-01

## Контекст

Після транспорту (ADR 0044) сервер лише генерував світ і віддавав карту: файл світу (ADR 0042) не створювався, років
не було, усі з'єднання ділили один потік. Потрібна сесія гри зі стан-машиною (`LOBBY → GENERATING → RUNNING ⇄ PAUSED
→ CLOSED`), фазами року й «Готово», щоб світ жив роками й зберігався. Систем рушія (економіка, війна…) ще немає, тож
роки поки «порожні».

## Рішення

- **Обсяг (рішення автора):** актор сесії, стан-машина, фази року, «Готово» одного гравця-хоста, порожній рік із
  записом у файл світу, протокол версії 2, кнопка «Готово» в клієнті. Лобі з кількома гравцями, таймери фаз, хост, що
  відновлює сесію з паузи, «Завантажити» — наступними кроками.
- **Рушій:** `engine/turn/TurnPipeline.resolve(state, content)` → `TurnResult(newState)` — заготовка конвеєра року:
  глибока копія → (фаз поки немає) → наступний рік → `WorldInvariants.check`. Вхідний стан не змінюється. Накази,
  події й записи коліс року додадуться з системами. `WorldState.START_YEAR` / `year(turn)` — календарний рік.
- **Протокол v2** (`Protocol.VERSION` = 2): `ClientMessage.Ready(turn)` — гравець закінчив накази року;
  `ServerMessage.Phase(turn, phase)` з `YearPhase` (`START_OF_YEAR`, `ORDERS`, `RESOLVING`, `REPORT`). Після карти —
  `START_OF_YEAR(0)`, `ORDERS(0)`; після «Готово» всіх — `RESOLVING(N)`, `REPORT(N)`, `START_OF_YEAR(N+1)`,
  `ORDERS(N+1)`. Не той рік, не фаза наказів, немає сесії — `Error` з `PHASE_CLOSED` (`turn`), з'єднання лишається.
  `CreateWorld` створює нову сесію; клієнт, що вже в сесії, полишає попередню (неявно — окремого повідомлення виходу
  поки немає).
- **`server/session/SessionActor`:** один потік на сесію (`kolo-session-<номер>`, демон); публічні методи
  (`generate`, `ready`, `leave`, `close`) лише ставлять завдання в чергу, тож стан сесії без блокувань.
  Генерація → файл світу (`WorldDirectory.create`) → карта → фази. Рік розв'язується, коли «Готово» натиснули всі
  гравці сесії (зараз — хост; гравець, якого чекали, пішов — рішення для решти). Рік пишеться в `WorldStore.saveTurn`
  однією транзакцією; лише після запису стан сесії переходить на новий рік. Помилка гри під час року
  (`InvariantViolationException`, `SaveFileException`) — `PAUSED`: стан і файл на попередньому році, гравці отримують
  `Error`, «Готово» відхиляється. Знімок для реплею в `crash-dumps/` — разом із наказами (зараз відтворювати нічого,
  крім стану, який і так у файлі). Помилка генерації — `Error` хостові й закриття сесії. Інший виняток у завданні —
  баг сервера: лог, з'єднання гравців закриваються, сесія закривається. Останній гравець пішов — сесія закривається
  (файл закривається, WAL прибирається); світ продовжиться відкриттям файлу.
- **Розв'язання року в актор передається функцією** (`UnaryOperator<WorldState>`, у грі — `TurnPipeline`): так
  пауза перевіряється тестом без зламаного рушія.
- **`Sessions`** — реєстр відкритих сесій сервера з наскрізними номерами; `closeAll` при зупинці чекає потоки сесій,
  щоб файли світів закрилися цілими.
- **Розмова й сесія розділені:** `ClientSession` (потік `kolo-connections`, раніше `kolo-session`) лише вітається й
  передає запити в актор; відповіді пише через `Peer` — абстракцію з'єднання (`send(messages, close)`), реалізовану
  каналом Netty. `Reply` прибрано: відповіді тепер асинхронні. Закрите з'єднання — `disconnected()` → вихід із сесії.
- **Тека світів (рішення автора):** `WorldDirectory` — ім'я файлу `world-<seed>`, зайняте — `world-<seed>-2`, `-3`…
  (наявні файли не перезаписуються; ім'я стає й назвою світу). Вбудований сервер — `WorldDirectory.defaultLocation()`:
  властивість `kolo.home` → `<kolo.home>/worlds`, Windows → `%APPDATA%\Kolo\worlds`, інакше `~/.kolo/worlds`. Окремий
  сервер — `--worlds DIR`, типово `./worlds`. Тести отримують `kolo.home` від збірки (`build/test-home/<задача>`,
  очищується перед запуском) — у домашню теку розробника нічого не пишеться.
- **Клієнт:** `ServerConnection.createWorld` → `GameStart(map, turn)` (завершується на `ORDERS` після карти; фази до
  карти — від попередньої сесії — пропускаються), `endYear(turn)` → новий рік (на `ORDERS` наступного року);
  одночасно — один запит. `WorldSource.newWorld/endYear`, `EmbeddedGame.start(Path)`. На карті — рік і кнопка
  «Готово»; помилки — у рядку стану (`ErrorTexts` спільний з екраном нового світу).

## Наслідки

- Одиночна гра тепер створює файл світу й проводить у ньому роки; світ переживе перезапуск, коли з'явиться
  «Завантажити».
- Окремий сервер обслуговує сесії паралельно: генерація одного світу не блокує інших клієнтів.
- Тест реплею вже можливий на порожніх роках: рік N із файлу + рушій → хеш року N+1 у файлі
  (`BundledSessionIntegrationTest`).
- Відкрите: вихід із сесії неявний; сесія без гравців закривається (для асинхронної гри на сервері — переглянути з
  таймерами); пауза без відновлення хостом; `PAUSED` клієнт бачить лише як помилку.
- Тести: рушій — `TurnPipelineTest`, `WorldStateTest`; протокол — формат і читання `ready`/`phase`, властивості,
  смок з роком; сервер — `SessionActorTest` (стан-машина, фази, неправильний рік, пауза, помилки генерації й теки,
  вихід, чужий співрозмовник, баг, свій потік), `SessionsTest`, `ClientSessionTest`, `WorldDirectoryTest`,
  `ConnectionHandlerTest`, `GameServerTest` (роки через Local і TCP, закриття сесій і файлів), смоки обох серверів з
  роком, `BundledSessionIntegrationTest` (5 років з реплеєм; бюджет порожнього року найбільшого світу з записом
  < 500 мс); клієнт — `ConnectionHandlerTest`, `ServerConnectionTest` (роки), `ClientSmokeTest` («Готово»).
