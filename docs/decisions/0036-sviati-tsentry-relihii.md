# 0036. Святі центри релігій і генерація світу

- **Статус:** прийнято
- **Дата:** 2026-09-30

## Контекст

GD §25.1: святий центр — провінція, яку релігія вважає священною; призначається після розміщення держав, у
провінції держави цієї віри або на нічийній землі. Держава обирає релігію колесом релігії держави (ADR 0021) у
ланцюжку своєї генерації, тож центри можна призначити лише тоді, коли згенеровано всі держави. Досі світ збирав CLI
(ADR 0035): карта → релігії → держави в циклі з накопиченням зайнятих назв; у рушії такого кроку не було.

## Рішення

- **Колесо святого центру** `generation_holy_center` (рішення автора: одне зважене колесо провінцій):
  `engine/generation/religion/HolyCenterWheel.generate(rng, content, map, religions, countryReligions)` →
  `StartHolyCenters(centers)` / `cell(r)` / `rolls()`, `HolyCenter(cell, roll)`. Сектори — провінції-кандидати за
  зростанням комірки, id `province_<комірка>`; `PARTIAL`, якість 50, без переваги. Потік `religion:<номер>` на кожну
  релігію: кількість релігій не зсуває центри попередніх.
- **Кандидати:** провінції держав цієї віри й нічийні провінції. Релігія без держав-вірян — лише нічийні (рішення
  автора); якщо й нічийних немає — увесь суходіл (на вбудованому контенті нічийні землі є завжди).
- **Спільні святині** (рішення автора): релігії не виключають провінції одна одної — одна провінція може бути святою
  для кількох вір (як Єрусалим; привід для конфліктів у подіях).
- **Вага провінції** — `balance.yaml` → `religion.holy_center` → `HolyCenterDef(base, fertility_pct, river,
  unclaimed_pct)` (останній параметр `ReligionBalanceDef`): (`base` + родючість × `fertility_pct` / 100 вниз +
  `river`, якщо є річка) × (нічийна — `unclaimed_pct` %, вниз), щонайменше 1. Святі місця — «землі обітовані»:
  родючі долини й річки. Ваги → частки 10 000 вниз, щонайменше 1 (як колесо материка, ADR 0033). Межі: `base`
  1..1000 (безплідна провінція має шанс), `fertility_pct` і `river` 0..1000, `unclaimed_pct` 1..100 (не 0 — інакше
  релігія без вірян лишилася б без центру).
- **Генерація світу** — `engine/generation/world/WorldGenerator.generate(rng, content, WorldSizeInput)` →
  `StartWorld(map, religions, countries, holyCenters)`: карта → релігії світу → держави по черзі від нульової (зайняті
  повні назви держав і імена людей накопичуються) → святі центри. Потоки — `map`, `religions`, `country:<n>`,
  `holy_centers` (перші три — ті самі, що були в CLI, тож держави за seed не змінилися). Варіант
  `generate(rng, content, map)` — світ на готовій карті (CLI перевіряє номер держави до генерації держав).
  `StartWorld.country(n)`, `countryReligions()`, `followers(r)`.
- **CLI `country`** генерує світ через `WorldGenerator`; у списку релігій світу — святий центр: провінція й держава
  (або «нічийна земля»).
- Святий центр поки не зберігається як `ProvinceId`: id провінцій і релігій з'являться разом зі `WorldState`.

Запропоновано (чекає підтвердження автора): `base` 10, `fertility_pct` 100, `river` 30, `unclaimed_pct` 20.

## Наслідки

На вбудованому контенті (60 світів усіх розмірів, 262 релігії):

- у релігій з вірянами центр на нічийній землі — ~11% (28 з 255), решта — у держав своєї віри; релігій без вірян
  ~3% (7), усі — на нічийній землі;
- центри тяжіють до «обітованих» земель: середня родючість 53 проти 40 по суходолу, річка — у 24% центрів проти 14%
  провінцій;
- збігів центрів різних релігій не було (кандидатів сотні); у тестовому світі без вірян збіги трапляються;
- генерація найбільшого світу (16 гравців, багато NPC) — ~0,5–0,6 с, у межах бюджету генерації карти 2 с.
- Властивості генерації світу перевіряються на вбудованому контенті: у тестовому контенті рушія замало імен людей
  для світу з багатьма державами на довільних seed (та сама причина, що й відома нестабільність
  `StateReligionWheelPropertiesTest`).
