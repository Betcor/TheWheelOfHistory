# 0013. Колесо розміру армії

- **Статус:** прийнято
- **Дата:** 2026-09-29

## Контекст

Колесо 10 ланцюжка генерації (GD §4.1) визначає, яка частка населення під зброєю, і залежить від
ідеології, підкласифікації та ВВП. GD §4.4 задає лише межі — 0,2–8% населення — і рідкісні крайні
сектори «майже без армії» та «вся нація під зброєю». Мітки `small_army` (< 0,5%) і `large_army`
(≥ 3%) уже є в `generation_tags` і на них реагують фрагменти передісторії.

## Рішення

- **Рівні — у контенті**, окремий файл `army.yaml` (ключ `sizes`, щоб поруч згодом лягли рівні
  вишколу), за зразком рівнів ВВП та ІЛР (ADR 0011, 0012): `id`, назва, опис, `share_bp` (частка
  населення під зброєю в базисних пунктах, `1..10000`), `tier`, `weight` (відносна `1..10000`),
  `quality` (`0..100`), `tags`. Порядок у файлі — порядок секторів, від найменшої армії до
  найбільшої: `share_bp` строго зростає, `tier` не спадає (код `OUT_OF_ORDER`).
- **Частка, а не чисельність**: населення визначить колесо з картою; чисельність армії = частка ×
  населення. Базисні пункти — звичайна одиниця часток у рушії, без дробів.
- **Результат — фіксоване значення рівня**, як у колесі ІЛР: без другого обертання всередині рівня.
- **Більша армія — «успіх»** з погляду переваги: мілітаристський лад і багатство зсувають шанси до
  більших армій. Якість для стріків при цьому не росте до «дуже доброї» — величезна армія є тягарем
  для економіки.
- **ВВП дає перевагу за рівнем результату свого рівня** тим самим `StartGdp.advantage(perStep)`, що
  й у колесі ІЛР, з власним коефіцієнтом `generation.army_size_gdp_advantage`.
- **Лад** — модифікатори держави з ціллю `wheel:generation_army_size`, як у ADR 0009–0012.
- `engine/generation/country/ArmySizeWheel.generate(rng, content, modifiers, gdp)` →
  `StartArmySize(size, shareBp, tags, quality, rolls)`; потік `army_size`.
- Мітки рівнів — ще одне джерело міток для умов передісторії.

## Запропоновані числа (чекають підтвердження автора)

- Рівні: майже без армії 0,2% / мала 0,4% / скромна 0,8% / звичайна 1,5% / велика 3% / масова 5% /
  вся нація під зброєю 8%; ваги 5 / 15 / 22 / 28 / 18 / 9 / 3 (%); якість 15 / 30 / 40 / 50 / 60 /
  70 / 80; рівні результату `crit_fail` / `fail` / `fail` / `partial` / `success` / `success` /
  `crit_success`; `small_army` — два нижчі рівні, `large_army` — три верхні.
- `generation.army_size_gdp_advantage`: 10 (від −20 для злиднів до +20 для багатства).
- Перевага ладу `wheel:generation_army_size` за GD §4.2 («тоталітаризм +армія, хунта +армія»):
  тоталітаризм +10; військова хунта, мілітаризм +15; реваншизм, спадкова імперія +10. Від'ємних
  модифікаторів поки немає — GD їх не згадує. Інтеграційний тест тримає перевагу ладу й окремо внесок
  ВВП у `−50..50`.

## Наслідки

- Колесо вишколу (GD §4.1, №12) — наступне: залежить від ВВП, ідеології й розвиненості; його рівні
  (GD §4.4: 5 рівнів з модифікаторами −20..+20) ляжуть у той самий `army.yaml`.
- Колесо доктрин (№11) залежить від географії, тож повністю — разом із картою.
- Чисельність армії й її розміщення — разом із населенням і картою.
