# 0012. Колесо індексу людського розвитку

- **Статус:** прийнято
- **Дата:** 2026-09-29

## Контекст

Колесо 9 ланцюжка генерації (GD §4.1) визначає ІЛР і залежить від ВВП та ідеології. ІЛР — показник
`0..100` (GD §5.1, `Stat.HDI`). GD не задає ні рівнів ІЛР, ні того, як ВВП зсуває шанси; ADR 0011
лишив відкритим, чи брати ВВП за положенням рівня, чи за його мітками.

## Рішення

- **Рівні — у контенті**, окремий файл `hdi.yaml`, за зразком рівнів ВВП (ADR 0011): `id`, назва,
  опис, `hdi` (у межах `Stat.HDI`), `tier`, `weight` (відносна `1..10000`), `quality` (`0..100`),
  `tags`. Порядок у файлі — порядок секторів, від найнижчого до найвищого: `hdi` строго зростає,
  `tier` не спадає (код `OUT_OF_ORDER`).
- **Результат — фіксоване значення рівня** (рішення автора): ІЛР держави = `hdi` обраного рівня,
  без другого обертання всередині рівня. Модифікатори `stat:hdi` ладу й передісторії діють поверх
  нього, як і раніше.
- **ВВП дає перевагу за рівнем результату свого рівня** (рішення автора): `OutcomeTier.step()`
  (`crit_fail` −2, `fail` −1, `partial` 0, `success` +1, `crit_success` +2) ×
  `generation.hdi_gdp_advantage` з балансу. `gdp.yaml` не отримує полів для наступних коліс, а той
  самий прийом підійде колесам армії й вишколу (GD §4.1: залежать від ВВП). Щоб не шукати рівень у
  контенті, `StartGdp` тепер зберігає `tier`; внесок рахує `StartGdp.advantage(perStep)` — рядок
  пояснення `gdp:<рівень>` / `gdp.<рівень>`, на частковому рівні внеску немає.
- **Лад** — модифікатори держави з ціллю `wheel:generation_hdi`, як у ADR 0009–0011.
- `engine/generation/country/HdiWheel.generate(rng, content, modifiers, gdp)` →
  `StartHdi(level, hdi, tags, quality, rolls)`; потік `hdi`. Якість для стріків — якість рівня.
- Мітки рівнів ІЛР — ще одне джерело міток для умов передісторії. Вбудовані рівні поки міток не
  дають: у словнику `generation_tags` немає міток ІЛР, а вигадувати мітки без фрагментів, що на
  них реагують, не варто.

## Запропоновані числа (чекають підтвердження автора)

- Рівні: дуже низький 15 / низький 30 / нижче середнього 45 / середній 60 / високий 75 / дуже
  високий 90; ваги 8 / 17 / 22 / 24 / 19 / 10 (%); якість 5 / 20 / 40 / 50 / 75 / 95; рівні
  результату `crit_fail` / `fail` / `fail` / `partial` / `success` / `crit_success`.
- `generation.hdi_gdp_advantage`: 15 (від −30 для злиднів до +30 для багатства).
- Перевага ладу `wheel:generation_hdi` — за знаком наявних `stat:hdi` (GD §4.2): демократія,
  соціал-демократія, соціалізм +10; тоталітаризм, олігархія, феодальна монархія, фундаменталізм
  −10. Інтеграційний тест тримає перевагу ладу й окремо внесок ВВП у `−50..50`.

## Наслідки

- Колеса армії й вишколу беруть ВВП тим самим `StartGdp.advantage` з власним коефіцієнтом.
- Колесо відомих людей (GD §4.1, №16) залежить від ІЛР — як саме, вирішимо разом із ним.
- Якщо з'являться мітки ІЛР для передісторії (напр. освічене населення), їх додають у
  `generation_tags` і в рівні `hdi.yaml`.
