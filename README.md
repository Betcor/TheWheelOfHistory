# Колесо Історії

Десктопна багатокористувацька покрокова пісочниця-генератор історій. Гравці генерують країни
серією зважених коліс фортуни й з 1 січня 1970 року живуть у спільному світі разом із NPC-державами:
економіка, будівництво, наука, війни, дипломатія, ООН, розвідка. Один хід — один рік. Кінця гри немає.

Режими: одиночна гра, hot-seat, LAN, окремий сервер.

> Проєкт на ранній стадії розробки — грати поки нема у що.

## Збірка

Потрібен лише JDK 17+ для запуску Gradle; JDK 25 для компіляції Gradle завантажить сам.

```
./gradlew check           # тести, форматування, архітектурні правила
./gradlew :client:run     # запуск клієнта
```
